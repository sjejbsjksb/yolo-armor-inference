# YOLO26n 装甲板视频推理与可视化

## 一、项目简介
本项目为计算机视觉课程第一次大作业。主要内容为：在西北农林科技大学实验室实景拍摄包含六类装甲板（B1, B2, B3, R1, R2, R3）的视频，并基于课程提供的 YOLO26n 预训练模型 (`best.pt`) 完成视频推理。

项目实现了对视频流的逐帧目标检测，可视化内容包括**检测框、类别标签、置信度以及模型预测的 4 个关键点**。此外，项目还统计并绘制了推理过程中所有检测目标的置信度分布直方图，以辅助分析模型的实际表现。

## 二、环境依赖与配置
### 1. 基础环境
*   **操作系统**：Windows 11
*   **Python 版本**：3.10.11（注：因 `ultralytics` 等库尚未适配 Python 3.13，强烈建议使用 3.10 版本）
*   **运行设备**：CPU（未使用 GPU 加速，推理速度满足非实时处理要求）

### 2. 依赖库 (`requirements.txt`)
本项目依赖以下 Python 库：
- `ultralytics`：YOLO 系列模型推理框架
- `opencv-python`：视频帧读取与视频写入
- `numpy`：数值计算与统计
- `matplotlib`：置信度分布图绘制

## 三、模型准备与放置位置
请将课程提供的模型权重文件 `best.pt` 放置于本项目根目录下（与 `infer.py` 位于同一层级）。

## 四、安装与运行说明
请在 Windows PowerShell 终端中依次执行以下命令：

### 1. 创建并激活虚拟环境
```powershell
python -m venv venv
.\venv\Scripts\activate
```

2. 安装依赖 (推荐使用清华源加速下载)

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

3. 执行推理脚本

假设输入视频文件名为 armor_video.mp4，运行命令如下：

```powershell
python infer.py --source armor_video.mp4 --weights best.pt
```

五、视频采集说明

· 采集地点：西北农林科技大学实验室
· 采集设备：手机（横屏拍摄）
· 视频内容：时长约 15 秒，画面中依次出现了 B1、B2、B3、R1、R2、R3 六类装甲板。采集过程中通过改变拍摄距离、角度，并利用了环境光线和反光效果，以全面测试模型的鲁棒性。

六、推理结果与统计分析

运行推理脚本后，将在项目目录下生成以下文件：

1. 可视化视频 (output_video.mp4)

该视频展示了模型对原始视频的逐帧推理结果。可视化内容严格基于模型输出，包括：

· 目标检测框
· 类别标签与置信度（如 B3 0.89）
· 模型输出的 4 个关键点（非检测框角点），标记清晰。

2. 置信度分布统计 (confidence_distribution.png)

为量化分析模型表现，代码统计了所有检测目标的置信度，并绘制了直方图：

· 总检测目标数：904 个
· 平均置信度 (Average Confidence)：0.7869

./confidence_distribution.png

分析：从分布图可以看出，大部分检测目标的置信度集中在 0.85 - 0.95 的高置信度区间，说明模型对多数装甲板的识别具有较高的确信度。低置信度样本（0.3 - 0.6）较少，主要出现在反光或模糊的帧中。

七、实际表现与问题处理

· 实际表现：模型对光照良好、距离适中的装甲板具有极高的检测精度和关键点定位精度，满足作业要求。
· 遇到的问题与处理：
  1. 漏检/误检：在反光强烈或装甲板距离过远时，偶尔出现漏检。处理方法为保证拍摄光照并适当调整拍摄距离。
  2. 环境配置报错：使用 Python 3.13 导致 ultralytics 安装失败。解决方法为更换至 Python 3.10.11 并配置国内镜像源。
  3. 路径拼写错误：运行初期因输入的视频文件名拼写错误导致 无法打开视频文件。修正路径后恢复正常。
